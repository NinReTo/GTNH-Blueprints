# Чертежи фабрик GTNH

Клиентский мод для Minecraft 1.7.10 и GT New Horizons 2.9.0. Показывает чертежи собственной голограммой и размещает блоки GregTech и Railcraft в одиночной игре.

Коды чертежей создаёт [калькулятор фабрики GTNH](https://github.com/NinReTo/GTNH).

1. Положите `build/gtnh-blueprints-0.1.7.jar` в папку `mods` экземпляра GTNH.
2. Соберите фабрику на сайте и нажмите «Скопировать код чертежа».
3. Над обычным или творческим инвентарём нажмите кнопку с блокнотом «Чертежи», затем «+ Схема». Мод прочитает код из буфера обмена и запишет его в `blueprints/factory-calculator` экземпляра игры.
4. Наведитесь на грань блока перед открытием инвентаря. Выберите чертёж и нажмите «Голограмма». Голубые контуры показывают свободные клетки, красные — занятые. Num 7 переносит чертёж к прицелу, Num 8 поворачивает на 90°, Num 9 скрывает и снова показывает. Клавиши можно поменять в настройках Minecraft.

В одиночном творческом мире «Автопостройка» использует позицию и поворот выбранной голограммы. Если голограмму ещё не показали, постройка начнётся у прицела. Темп достигает 50 блоков в секунду при стабильных тиках и снижается до 5 при нагрузке. Занятые клетки и незагруженные чанки пропускаются. В конце в чате появится число поставленных и пропущенных блоков.

При импорте сохраняются размеры, блоки, направления и соединения, которые есть в модели сайта. Рецепты машин, содержимое баков и сундуков, настройки покрытий и сущности в код не входят. Если для части схемы пока нет сопоставления с блоками игры, мод перечислит их и остановит размещение. Некоторые декоративные блоки сайта требуют отдельных сопоставлений для конкретных мультиблоков.

Код начинается с `GTNH1.`. За префиксом идёт список блоков в JSON, сжатый gzip и записанный в Base64URL. Чертёж самодостаточен. SHA‑256 используется как имя записи в локальной библиотеке и помогает избежать дублей. Импорт принимает только поля этого формата, без произвольных данных Minecraft.

## Сборка из исходников

Из корня проекта запустите `./minecraft-blueprints/build.ps1`. Нужны установленные Python и JDK 17 или новее. По умолчанию скрипт читает локальную папку игры и её библиотеки. Для другой установки передайте пути через `-Game` и `-Libraries`. Итоговый JAR содержит только файлы этого мода. Сборка читает зависимости из игры и не меняет её файлы.
